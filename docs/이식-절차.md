# 새 프로젝트에 붙이는 순서

> **각 단계에 「완료 판정」이 있다.** 없으면 단계가 아니라 희망이다.
> 특히 조용히 아무 일도 안 하는 실패는 판정 없이는 몇 달 뒤에도 안 드러난다.

## 0. 준비

### 0a. `claudeMdExcludes` 가 사용자 스코프에도 먹는가

`docs/0a_claudeMdExcludes-검증.md` 를 따른다. **결과별 분기까지 그 문서에 있다.**

- **완료 판정:** 그 문서의 「결과」 칸이 채워졌다

### 0b. `AGENTS.md` 를 진본으로 세운다

`template/AGENTS.md.tpl` → `AGENTS.md`, `template/CLAUDE.md.tpl` → `CLAUDE.md`.

**이걸 마지막이 아니라 처음에 한다.** 나중에 하면 그 사이에 쌓인 규칙을
전부 옮기는 재작업이 된다.

- **완료 판정:** 새 세션에서 `/context` 의 Memory files 에 `CLAUDE.md` 가 보이고,
  `AGENTS.md` 의 내용이 실제로 실렸다

## 1. 컴파일 훅

`~/.claude/settings.json` 의 `PostToolUse` 에 `compile-check.mjs` 를 건다
(형식은 `template/.claude/settings.json.tpl`).

**사용자 레벨에 건다.** 프로젝트의 `.claude/` 는 보통 git 에 없어서,
프로젝트 레벨에 걸면 워크트리에서는 훅이 존재하지 않는다 — 그리고 조용하다.

- **완료 판정:** 컴파일 안 되는 파일을 일부러 심고 편집해서 **차단되는지 본다.**
  통과만 보면 아무것도 증명되지 않는다 — 훅이 아무 일도 안 해도 통과는 나온다
- **실측을 남긴다:** 첫 실행과 이후 실행의 소요를 훅 머리 주석에 적는다.
  그 값을 모르면 `timeout` 도 근거 없이 정하게 된다

## 2. 지침 로드 기록

`InstructionsLoaded` 에 `instructions-log.mjs` 를 건다.

- **완료 판정:** `~/.claude/harness-instructions.log` **파일이 실제로 생겼다.**
  훅을 걸었다는 사실만으로는 판정하지 않는다 — 이벤트 이름이 틀렸거나
  훅이 죽어도 아무 오류가 나지 않는다

## 3. 문서 골격

`STATUS.md` · `RUNBOOK.md` · `decisions/` 를 만든다.
**`decisions/README.md` 는 결정이 10개를 넘을 때까지 만들지 않는다.**

- **완료 판정:** `STATUS.md` 의 「도는 것」에 계획이 아니라 사실이 적혀 있다

## 4. 마이그레이션 보호

DB 마이그레이션을 쓰는 프로젝트에만 해당한다.

- **완료 판정 둘:** 커밋된 마이그레이션 편집이 **차단되고**,
  아직 커밋 안 된 새 마이그레이션 편집은 **통과한다.**
  뒤쪽이 더 중요하다 — 거짓 차단이 잦으면 사람이 게이트를 끄고,
  꺼진 게이트는 없는 것보다 나쁘다(있다고 믿기 때문에)

## 5. 커밋 게이트

`commit-checklist.mjs` 를 `PreToolUse`(Bash)에 건다.
`.claude/harness-budgets.json` 으로 문서 예산을 정한다.

- **완료 판정:** 열쇠말 하나만 빼도 **그 항목을 지목해** 다시 막힌다

## 6. 픽스처 게이트

테스트가 버전관리 밖의 픽스처에 의존하면 만든다.

- 게이트 앞에 **이미 있는 삼킴부터 없앤다** — `catch (IOException) { return 빈값; }`
  같은 것이 있으면 게이트를 켜도 헛돈다
- **극성을 뒤집는다.** 기본을 required 로 두고 끄려면 환경변수를 명시하게.
  켜야 도는 게이트는 켜는 사람이 없어 존재하지 않는 것과 같다
- 테스트 러너가 **건너뛴 수를 마지막 줄에 크게 찍게** 한다

- **완료 판정:** 픽스처를 치우면 빌드가 **실패한다** (skip 이 아니다)

## 7. 라우팅 점검

결정이 10개를 넘으면 표를 만들고 `routing-lint.mjs` 를 주기적으로 돌린다.

- **완료 판정:** `node scripts/routing-lint.mjs decisions/README.md` 가 0 으로 끝난다
