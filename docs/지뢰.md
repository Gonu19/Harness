# 밀려난 지뢰 — 보관

`RUNBOOK.md` 지뢰표에서 밀려난 줄이 여기 온다. **지우지 않는다**(`D10`) —
"이제 안 밟는다" 는 판단이 틀리면 다음 세션이 같은 시간을 쓴다.
다시 밟았으면 `RUNBOOK.md` 로 되살린다. 그 사실이 `D10` 의 뒤집힐 조건을 잰다.

`docs/` 는 자유 구역이라 예산이 없다. 세션마다 읽지 않는다 — 막혔을 때 grep 한다.

| 증상 | 진짜 원인 | 밀려난 때 |
|---|---|---|
| 치환이 "찾지 못함" 으로 실패 | 앞선 편집으로 앵커가 바뀌었다. 다시 읽고 잡는다 | `7e9c357` |
| 락이 안 풀린다 | `process.exit()` 은 `finally` 를 건너뛴다. `process.on('exit')` 로 (`core/lock.mjs` 주석) | `7e9c357` |
| Bash heredoc 이 거부됨 | 워크트리 격리 가드. 파일은 Write 도구로 만든다 | `72c983a` |
| `sed -i` 가 일부만 바꿨다 | 패턴 여럿 중 **안 맞은 것은 조용히 무동작**. 오류가 없다. Edit 로 한 곳씩 | D11 (자리) |
| git 훅이 발화하지 않는다 | 확장자 없는 POSIX 스크립트여야 한다. `.bat`·`.cmd` 는 **조용히** 무시 — 지금은 `adapters/git/install.mjs` 가 놓는다 | D15 (자리) |
| Windows `python` 이 파일을 못 연다 | Git Bash 경로(`/a/...`)를 모른다. `A:\...` 로 준다 | D15 (자리) |
| 커밋 게이트가 새 파일을 못 봤다 | PreToolUse 는 명령이 **돌기 전**이다. 같은 명령이 **만드는** 파일(`printf > x && git commit`)은 없다. git 계층이 받는다. 파일은 Write 로 먼저 만든다 | D17 (자리) |
| 커밋 게이트가 "저장소를 알 수 없다" | `cd "$VAR" && git commit` — 변수 경로는 풀지 않는다. 경로를 그대로 적는다 | D17 (자리) |
| `spawn EINVAL` | Windows 는 `.bat`·`.cmd` 를 셸 없이 못 띄운다. `cmd.exe /d /s /c` 로 감싸거나 JS 진입점을 `node` 로 직접 불러 셸을 피한다 | D22 (자리) |
