## D3. 학습은 관측만 켜고 승격은 손으로 한다 (2026-09-07)

**변경.** `continuous-learning-v2` 를 **쓴다면** 관측(`observations.jsonl`)과
프로젝트 범위 instinct 생성까지만 켠다. `/evolve` 자동 실행과 project→global
`/promote` 는 끈다. 승격 목적지는 글로벌 skill 이 아니라 **그 프로젝트의
`AGENTS.md` 나 `RUNBOOK.md` 지뢰표**이고, 주 1회 사람이 손으로 옮긴다.

> **지금 상태: 켜지 않았다 (2026-09-09 확정).**
> 위는 "켤 때 이렇게 켠다" 는 조건이지 도입 사실이 아니다.
> `~/.claude/settings.json` 에 `observe.sh` 등록 **0건**.
>
> **안 켠 이유.** 이 도입의 값은 "주 1회 사람이 instinct 를 훑어 손으로 옮기는"
> 의례에서 나오는데 **그 의례가 아직 없다.** 의례 없이 관측만 켜면 비용만 낸다 —
> 관측 훅은 `PreToolUse`·`PostToolUse` 양쪽에 붙어서 **편집 한 번에 도는 훅이
> 3개에서 5개가 된다.** 아래 「뒤집힐 조건」의 첫 항목이 정확히 이것을 시험한다.
> 순서를 지킨다: 먼저 `RUNBOOK` 지뢰표와 `decisions/` 로 손 기록을 굴려 보고,
> **같은 설명을 반복하고 있다는 것이 관측되면** 그때 켠다.

**근거.** CL v2 는 관측 5회로 confidence 0.7 instinct 를 만들고, `/evolve` 가
그것을 skill 로 올린다. 이 저장소의 규율은 정반대다 — **"통과는 근거가 아니다",
"변조로 검증한다".** 관측 빈도는 근거가 아니다. **자주 일어난 일과 옳은 일은
다르다.**

그리고 여기엔 이미 같은 문제를 사람 판단으로 푸는 장치가 있다: 관측은
`RUNBOOK.md` 지뢰표 한 줄, 결정은 `decisions/`, 승격 규칙은 "같은 도구 실패가
두 번째면 결정이다". CL v2 의 confidence 임계값은 그 규칙의 자동화 버전인데,
**자동화된 쪽은 왜 승격됐는지를 사람이 못 본다.**

비용도 있다. 승격된 skill 은 컨텍스트를 먹는다 — `scripts/routing-lint.mjs` 가
결정당 약 400바이트를 재는 그 예산을, 자동 승격은 **사람 눈 밖에서** 쓴다.

관측만 켜는 것은 값이 있다. 여러 프로젝트를 오가면 "이 저장소는 이렇게 쓴다"
를 매번 다시 설명하게 되고, v2.1 의 project-scoped instinct 가 그걸 푼다.
푸는 것은 **기억 못 하는 문제**이고, 만들지 않는 것은 **검증 안 된 규칙이
스며드는 문제**다.

**선행 확인 — 통과 (2026-09-09).** v2.1 의 훅·스크립트가 전부 `.sh` 이고
`${XDG_DATA_HOME:-~/.local/share}` 에 쓴다. Windows 에서 안 돌면 조용히
아무것도 안 배우고, 그건 "배우는 중" 과 구별되지 않는다.

```bash
bash ~/.claude/skills/continuous-learning-v2/scripts/detect-project.sh; echo "exit=$?"
```

`exit 0` 이고 `~/.local/share/ecc-homunculus/projects/<해시>/` 가 실제로 있다.
Git Bash 에서 돈다는 뜻이다. **다만 스크립트는 출력이 없다** — 이 확인은
"실행된다" 까지만 말하고 "관측이 쌓인다" 는 말하지 않는다. 그건 훅을 건 뒤
`observations.jsonl` 이 커지는지로 판정한다.

**뒤집힐 조건.**

- 주 1회 손 승격이 **실제로 안 일어나면**(두 달 연속 0건) 자동화가 없어서가
  아니라 관측 자체가 값이 없다는 뜻이다. 그때는 관측도 끈다
- instinct 에 "왜 승격됐는지" 를 사람이 검토 가능한 형태로 남기는 장치가
  생기면 자동 승격을 다시 잰다. **근거를 볼 수 있는 것이 조건이다** —
  confidence 숫자는 근거가 아니다
- 선행 확인이 실패하면(Windows 에서 안 돌면) 이 결정은 성립하지 않는다.
  그때는 도입 자체를 다시 정한다
