## D17. 구현 경로는 선언하고, 기본값이 안 맞으면 표가 말한다 (2026-09-29)

**변경.** 게이트가 "구현"·"테스트"·"마이그레이션" 으로 보는 경로를
`.claude/harness-gates.json` 의 `source` · `test` · `migrations` 로 선언한다(`core/gates.mjs`).
기본값은 `src/` · (`src/test/` `test/` `tests/` `__tests__/` `spec/` + 테스트 파일 이름) ·
`db/migration/`. 기본값의 구현 경로가 저장소에 없으면 `gates-report` 가 그 사실을 말한다.
선언 파일이 깨졌으면 기본값으로 넘어가지 않고 `cannot` 이다.

같은 자리에서 고친 것 — STATUS 동반과 테스트 알림은 `src/main`·`src/test`(Gradle 배치)
대신 "구현 중 테스트가 아닌 것" 과 "테스트" 로 센다. Stop(D11)은 `source` 를 선언했으면
커밋 게이트와 같은 정의를, 아니면 문서·설정(`.claude/` · `.gitignore` 등)을 뺀 전부를 본다.
Gradle 은 추가 소스 세트(`compile<세트>Java`)와 멀티 모듈(`-p <모듈>`)을 본다.

**근거.**

*하드코딩이 조용히 빠졌다.* `^src/` 만 구현으로 봐서 `app/`·`lib/`·`packages/` 저장소에서는
D7·열쇠말·STATUS 동반이 전부 "문서만 바뀌는 커밋" 으로 지나갔다. TS·Python 저장소는
`src/main/` 이 없어 STATUS 동반이 한 번도 안 떴다. 오류도 경고도 없었다.

*추측하지 않는다.* 디렉터리 이름으로 소스를 고르면 틀릴 때 거짓 차단(제2원칙)이거나
조용한 누락(제1원칙)이다. `stack:none` 과 같은 모양 — **사람이 한 번 선언한다.** 선언은
기록이라 읽을 수 있다. 기본값이 안 맞는다는 사실은 도구가 말한다.

*하네스 문서는 선언하지 않는다.* `PRD.md`·`STATUS.md`·`decisions/OPEN.md` 는 하네스가
놓는 규약이다. 프로젝트 배치가 아니다.

**버린 대안.**

| | 왜 버렸나 |
|---|---|
| 스택 표식으로 소스 디렉터리 추측 | 틀리면 조용하다. 모노레포에서 답이 여럿이다 |
| `src/` 가 없으면 전부를 구현으로 | 문서 저장소에서 모든 커밋이 막힌다 |
| 선언 없으면 게이트를 끈다 | 이식 직후 기본 배치(`src/`)가 맞는 저장소까지 꺼진다 |

**뒤집힐 조건.**

- 선언을 빠뜨려 게이트가 빠진 일이 `gates-report` 경고에도 **반복되면** — 이식 시
  `harness-init` 이 묻도록 앞당긴다
- 기본 테스트 이름 패턴이 구현 파일을 테스트로 오인하는 일이 관측되면 패턴을 좁힌다
