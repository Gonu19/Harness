## D18. 비밀값은 형식이 확실한 것만 두 계층에서 막는다 (2026-09-29)

**변경.** 커밋에 **추가되는 줄**에서 공급자 키 형식(AWS · GitHub · Slack · Google ·
Stripe live · Anthropic · OpenAI)과 개인 키 블록을 찾고, 새 `.env` 파일(예시 파일 제외)을
막는다(`core/secrets.mjs`). git 계층은 `pre-commit`, 도구 계층은 `commit-checklist` 가
같은 판정을 부른다. 도구 계층은 같은 명령의 `git add` 가 올릴 것도 미리 본다.
문서 예시는 그 줄의 `harness:allow-secret` 표식으로 통과한다. 공급자가 공개한
`…EXAMPLE…` 값은 표식 없이 통과한다. 메시지에는 값의 앞 네 글자만 찍는다.

같은 검토에서 — 하네스를 셸로 끄는 명령(`harness-off` · `.claude/settings` 편집)을 묻는
`ask` 규칙을 **사용자 전역**에 건다(`install.mjs`). D15 는 "에이전트가 켜고 끄지 않는다 —
D13 의 ask 에 걸린다" 고 적었지만, 그 규칙은 `Edit(~/.claude/**)` 뿐이라 Bash·PowerShell 이
지나갔다. 훅 명령 줄은 `|| exit 2`(PowerShell 은 `if (-not $?) { exit 2 }`)로 감싸고 셸을
`shell` 필드에 적는다 — node 가 뜨지도 못하면(127) Claude Code 는 막지 않기 때문이다.

**근거.**

*실측.* 샘플 프로젝트에서 AWS 키가 든 문서가 두 계층을 통과했다.

*되돌릴 수 없다.* 원격에 올라간 커밋은 이력을 지워도 이미 복제됐다. D13 은 되돌리기
어려운 **명령**을 사람에게 묻게 했는데, 비밀값은 명령이 평범한 `git commit` 이라 물을
자리가 없다. 내용을 봐야 한다.

*좁게.* 엔트로피 추정은 해시·UUID·픽스처에 매일 걸린다. 거짓 차단이 잦으면 사람이
게이트를 끈다(제2원칙). 형식이 확실한 것만 잡으면 놓치는 것이 생기지만, 켜져 있는
좁은 게이트가 꺼진 넓은 게이트보다 낫다.

*빠져나가는 길이 커밋에 남는다.* 표식은 그 줄에 적혀 커밋된다 — 무엇을 왜 통과시켰는지
나중에 읽힌다. `--no-verify` 처럼 흔적 없이 넘는 길이 아니다.

**버린 대안.**

| | 왜 버렸나 |
|---|---|
| gitleaks 등 외부 도구 호출 | 설치가 필요하다. 없으면 `cannot` 이라 모든 커밋이 막히거나, 통과로 접어 제1원칙을 어긴다 |
| 엔트로피 기반 탐지 | 거짓 차단 |
| 저장소 전체를 매번 검사 | 이미 커밋된 값 때문에 그 파일을 고치는 모든 커밋이 막힌다 |
| 알리기만 | 되돌릴 수 없는 사고다. 알림은 지나간다 |

**뒤집힐 조건.**

- 표식(`harness:allow-secret`)이 반사적으로 붙는 일이 관측되면(차단 기록 · `git log -S`)
  표식에 **이유**를 요구한다
- 형식 목록 밖의 비밀값이 새어 나간 일이 생기면 그 형식을 더한다 — 넓히는 근거는 사고다
- 거짓 차단이 차단 기록(D14)에 되풀이되면 그 규칙을 좁힌다

**관련.** [[D13_되돌리기-어려운-명령은-막지-않고-묻는다]] — 명령이 아니라 내용이라 여기서 막는다.
[[D15_하네스가-고장나면-사람이-파일-하나로-끈다]] — 그 스위치를 셸로 못 켜게.
