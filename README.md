# Harness — 이식용 에이전트 하네스

AI 코딩 에이전트가 **"검사를 안 했다"와 "검사를 통과했다"를 같은 침묵으로
내보내지 못하게** 하는, 다른 프로젝트에 붙이는 하네스.

게이트(편집·커밋) · 이식(템플릿·온보딩 스킬) · 반복(회고) · 게이트 생존 판정.
Claude Code 에서도 돌고, git 훅으로 **어느 에이전트에서도** 돈다.

## 하나만 읽는다면

> **`skip` 은 "내 소관이 아니다" 한 가지 뜻으로만 쓴다.
> 소관인데 판정에 실패했으면 전부 `cannot` 이고, 그건 `pass` 로 접히지 않는다.**

게이트가 죽는 방식은 여럿이다 — stdin 깨짐 · 실행 파일 없음 · 타임아웃 킬 ·
게이트 자신의 버그. 그 전부가 조용한 종료로 나가면 **"검사를 안 돌렸다"와
"통과했다"가 같은 출구를 쓴다.** 그러면 게이트가 있어도 없는 것과 같고,
**있다고 믿기 때문에 더 나쁘다.** `core/verdict.mjs` 가 이 규칙을 종료 코드에서
떼어내 강제한다.

## 여기에 없는 것

**결정의 *내용*.** 형식만 준다 — 남의 결론을 규칙으로 물려받으면 외부 배포판을
검토 없이 받는 것과 같다.

## 어디를 보나

| 알고 싶은 것 | 파일 |
|---|---|
| 무엇을 왜 만드나 · 품질 목표 · 기능별 완료 판정 | `PRD.md` |
| 지금 구조 (C4 L1·L2) | `ARCHITECTURE.md` |
| 지금 무엇이 되어 있고 다음이 무엇인가 | `STATUS.md` |
| 명령 — 검증 · 게이트 생존 · 예산 | `RUNBOOK.md` |
| 작업 규칙 (진본) | `AGENTS.md` |
| 왜 그렇게 정했나 · 아직 안 정한 것 | `decisions/` · `decisions/OPEN.md` |
| **새 프로젝트에 붙이는 순서** | `docs/이식-절차.md` |
