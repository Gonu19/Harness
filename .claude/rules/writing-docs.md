# 문서를 쓸 때

`AGENTS.md` 에서 내려온 규칙이다. 문서를 건드릴 때만 로드된다.

## 관측과 결정을 가른다

| | 예시 | 어디로 |
|---|---|---|
| **관측** — 선택지가 없다 | "`git checkout -- <경로>` 는 인덱스에서 복원한다" | `RUNBOOK.md` 지뢰표 한 줄 |
| **결정** — 대안·근거·뒤집힐 조건이 있다 | "파일 내용은 Write 도구로 쓴다" | `decisions/` |

**같은 도구 실패가 두 번째면 관측이 아니라 결정이다.** 첫 번째는 한 줄로 적고 넘어간다.
전부 결정으로 만들면 결정 로그가 도구 사고 속도로 자라고,
결정 하나당 항상 로드되는 라우팅 파일이 약 400바이트씩 커진다(실측).

## 새 결정

- 이름: `decisions/D<번호>_<제목-하이픈>.md` (번호 재사용 금지)
- **최소 3어절 이상의 서술형 파일명.** `ls` 출력이 목차 역할을 한다
- 본문에 **근거**와 **뒤집힐 조건**을 반드시 적는다
- **원본은 고치지 않는다.** 생각이 바뀌면 새 번호로 "D\<n\>을 고친다" 로 잇는다

## 예산을 넘겼을 때

**늘리지 말고 내려보낸다.** 그런데 내려보낼 곳이 있어야 한다 —

| 파일 | 배출구 |
|---|---|
| `STATUS.md` | `docs/` · `decisions/`. **지나간 사건은 상태가 아니다** — 지운다 |
| `RUNBOOK.md` | 죽은 지뢰 삭제 · 스크립트가 스스로 찍는 것은 옮겨 적지 않는다 |
| `AGENTS.md` | `.claude/rules/` 의 `paths:` — 조건부 로드 |

**한도는 배출구가 있을 때만 한도다.** 배출구 없는 한도는 벽이고, 벽에 부딪히면
사람은 시행 중인 규칙을 지워서 자리를 만든다. 그건 파일이 큰 것보다 나쁘다.

## `.claude/rules/` 로 내려보낼 때 주의

`paths:` 조건부 로드는 **Claude Code 기능이다.** Codex·Gemini·Cursor 는
`AGENTS.md` 만 읽는다. 그래서 내려보낸 규칙 파일은 `AGENTS.md` 에 **경로로
한 줄 열거**해 둔다. 규칙이 사라지는 게 아니라 덜 최적화될 뿐이어야 한다.
